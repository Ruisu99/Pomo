# Pomo Focus Blocker (Browser-Erweiterung)

Blockiert ablenkende Websites während aktiver Fokus-Sessions in der Pomo-App.

## Installation (Chrome / Edge / Brave)

1. Öffne `chrome://extensions` (oder `edge://extensions`)
2. Aktiviere **Entwicklermodus**
3. Klicke **Entpackte Erweiterung laden**
4. Wähle diesen `extension/` Ordner

## Nutzung

1. Öffne die Pomo-App im Browser
2. Schalte **Fokusmodus** ein — der Timer startet automatisch
3. Während einer **Arbeitsphase** werden gelistete Seiten blockiert
4. In den **Pausen** sind alle Seiten wieder erreichbar

Die Blockliste kannst du in den Pomo-Einstellungen anpassen.

## Hinweis

- Die Erweiterung blockiert nur Websites im Browser, nicht native Apps (z.B. YouTube-App)
- Für App-Blockierung auf macOS: Systemeinstellungen → Bildschirmzeit → App-Limits
